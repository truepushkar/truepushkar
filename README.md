I build web apps around problems that are easy to see but needlessly complicated to solve — attendance systems that replace paper registers, booking that lands the second a window opens, lightweight tools that need no account. Main stack: <kbd><img src="https://skillicons.dev/icons?i=py" width="18" height="18" align="absmiddle" alt="" /> Python</kbd> + <kbd><img src="https://skillicons.dev/icons?i=flask" width="18" height="18" align="absmiddle" alt="" /> Flask</kbd> with hand-written <kbd>Jinja</kbd> and whichever database fits — <kbd><img src="https://skillicons.dev/icons?i=mongodb" width="18" height="18" align="absmiddle" alt="" /> MongoDB</kbd>, <kbd><img src="https://skillicons.dev/icons?i=mysql" width="18" height="18" align="absmiddle" alt="" /> MySQL</kbd> or <kbd><img src="https://skillicons.dev/icons?i=sqlite" width="18" height="18" align="absmiddle" alt="" /> SQLite</kbd>. Lately mostly <kbd><img src="https://skillicons.dev/icons?i=ts" width="18" height="18" align="absmiddle" alt="" /> TypeScript</kbd> and <kbd><img src="https://skillicons.dev/icons?i=workers" width="18" height="18" align="absmiddle" alt="" /> Cloudflare Workers</kbd>: gateways that let any harness talk to a provider it was never written for, plus small backend-free tools. **29 public repos, 13 of them live** across `truepushkar` and `nullstacks`. I care more about solving the right problem than collecting technologies.
