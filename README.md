## About

I build web applications around problems that are easy to see but often unnecessarily complicated to solve — attendance systems that replace paper registers, lightweight tools that don't demand an account before they're useful.

My primary stack is **Python + Flask**, with hand-written Jinja templates and whichever database fits the problem. Lately it is mostly TypeScript and Cloudflare Workers — gateways that let any harness talk to a provider it was never written for. I care more about solving the right problem than collecting technologies.
