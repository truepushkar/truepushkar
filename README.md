I build web apps around problems that are easy to see but needlessly complicated to solve — attendance systems that replace paper registers, booking that lands the second a window opens, lightweight tools that need no account. Main stack: <img src="https://skillicons.dev/icons?i=py" width="20" height="20" align="absmiddle" alt="" /> Python + <img src="https://skillicons.dev/icons?i=flask" width="20" height="20" align="absmiddle" alt="" /> Flask with hand-written Jinja and whichever database fits — <img src="https://skillicons.dev/icons?i=mongodb" width="20" height="20" align="absmiddle" alt="" /> MongoDB, <img src="https://skillicons.dev/icons?i=mysql" width="20" height="20" align="absmiddle" alt="" /> MySQL or <img src="https://skillicons.dev/icons?i=sqlite" width="20" height="20" align="absmiddle" alt="" /> SQLite. Lately mostly <img src="https://skillicons.dev/icons?i=ts" width="20" height="20" align="absmiddle" alt="" /> TypeScript and <img src="https://skillicons.dev/icons?i=workers" width="20" height="20" align="absmiddle" alt="" /> Cloudflare Workers: gateways that let any harness talk to a provider it was never written for, plus small backend-free tools. **29 public repos, 13 of them live** across `truepushkar` and `nullstacks`. I care more about solving the right problem than collecting technologies.
