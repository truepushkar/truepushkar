### 🛰️ Pre-flight

Hi — I'm **Pushkar**. I build web apps for problems I can see from where I'm
standing: attendance that shouldn't need a register, a paste bin that shouldn't
need an account, a campus that shouldn't need six different portals.

Almost everything I ship is **Python on Flask**, hand-written Jinja templates,
and whichever database the problem actually needs — then straight onto Vercel.
